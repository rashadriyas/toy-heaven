# Toy Heaven Website

This folder contains the static Toy Heaven website prepared for GitHub Pages.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `toy-heaven`).
2. Upload the **contents of this folder** to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for deployment and open the published URL.

Keep `index.html` at the repository root and keep the `HTML`, `CSS`, `Java scripting`, `images`, `images for products`, and `icon images` folders in their current locations. Paths are case-sensitive on GitHub Pages.

## Before submitting
- Open every page on the published website and check its links and images.
- Test search, filters, cart, wishlist, checkout, and forms.
- Run HTML/CSS validation, WAVE, Lighthouse, and responsive checks.
- GitHub Pages is static hosting; it does not run server-side code or provide a database. Any forms requiring a backend need a separate service.
